# ⚔️ Math Fighter

빠른 계산과 전투를 결합한 **수학 액션 게임**입니다.

문제를 푸는 행위가 전투의 흐름을 끊는 별도 퀴즈가 아니라, 공격과 진행 자체에 자연스럽게 연결되는 플레이를 목표로 합니다.

## 🚧 Status

현재 개발 중인 프로젝트입니다.

이 공개 저장소는 프로젝트 소개를 위한 공간이며, 게임의 개발 소스 전체가 공개되어 있지는 않습니다.

## 🎮 Project

- [Math Fighter 프로젝트 페이지](https://fiverocksgames.github.io/games/math-fighter/)

## 🎯 Design Goals

- 빠른 계산과 전투 감각을 하나의 흐름으로 연결하기
- 반복 플레이에서 난이도와 템포가 자연스럽게 올라가게 하기
- 모바일 환경에서 입력과 피드백을 명확하게 만들기
- 학습보다 먼저 게임으로서 다시 플레이하고 싶은 경험 만들기
